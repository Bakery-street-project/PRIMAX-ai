## ⚡ What is PRIMAX AI?

PRIMAX AI is a **self-learning autonomous system** that uses the **Hitchhiker's Equation** and **AutomationCodex mechanical process** - NOT a traditional LLM.

Built on [Smoothoperator](https://github.com/Bakery-street-project/Smoothoperator) foundation.

### Core Principles

- 🧬 **Self-Learning** - Adaptive intelligence via AutomationCodex
- ⚙️ **Mechanical Process** - Deterministic automation, not probabilistic
- 🔢 **Hitchhiker's Equation** - Mathematical foundation for decision making
- 🚀 **Free Cloud** - Deploy on Render.com (free tier → paid scaling)
- 🔐 **Encrypted** - AES-256 vault for secrets
- 📡 **API-First** - FastAPI with OpenAPI docs

## 🚀 Quick Deploy

```bash
# Clone
git clone https://github.com/Bakery-street-project/PRIMAX-ai.git
cd PRIMAX-ai

# Initialize vault
python src/vault_manager.py init

# Run locally
uvicorn src.main:app --reload

# Or with Docker
docker build -t primax-ai .
docker run -p 8000:8000 primax-ai
```

**API Docs:** http://localhost:8000/api/docs
